Spacing and shape

Spacing base: 4 px. Apply a consistent spacing scale (4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 px). Cards and fields use restrained square corners; 44 px minimum target size; use borders and whitespace rather than heavy shadows.

02 · Responsive layouts

One grid, three useful views

Responsive frame targets: desktop 1440 px, tablet 768 px and mobile 390 px. Scale content with Auto Layout and constraints; use a max-width container to preserve comfortable reading measure.
