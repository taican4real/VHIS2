# Victory Heritage International School Website

Responsive multi-page website prototype and implementation planning materials for Victory Heritage International School (VHIS).

## Current status

- The public-facing prototype covers Nursery, Primary and Secondary in one institutional website.
- Institutional details that have not been verified are presented as placeholders.
- The printable application form is a review template, not an approved school document.
- The Phase 13 architecture direction was approved by the VHIS project owner on 2 November 2026.
- Phase 14 setup is pending provider, account ownership, budget, privacy and operational decisions.
- No production CMS, database, external service, or live enquiry processing is configured.

## Preview

Open `prototype.html` in a browser to use the responsive prototype launcher. Open `index.html` to view the homepage directly.
